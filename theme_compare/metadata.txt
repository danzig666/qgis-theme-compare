about=Shows which layers and groups are visible in one map theme but not in the other. Either side can be the current state of the Layers panel, so you don't have to save it as a theme first. Optionally also compares named styles, switched-on legend classes (categories/rules) and the expanded/collapsed state. Differences can be filtered, exported to CSV, copied to the clipboard, and copied from one theme to the other with a right click.
